# Журнал изменений

## 1.0.0

Релиз для проверки владельцем и тестировщиком.

- Тестовый сайт на GitHub Pages (`https://mfk096.github.io/-/`) и debug APK в релизе `latest-apk`.
- QR на этикетке ведёт на карточку на этом сайте. Адрес задаётся `VITE_PUBLIC_APP_URL`.
- Раздел «Пользователи» для администратора, смена своего пароля, приглашение по email.
- Смена префикса переписывает коды всех единиц этой номенклатуры, номера сохраняются. Старый код открывает единицу и просит заменить этикетку.
- Места без типа уровня: перенос к другому родителю и вставка уровня выше.
- Место и статус обязательны для новой единицы и для импорта. Склад — место в дереве и статус «Резерв».
