# Чек-лист тестировщика, релиз 1.0

Отмечайте пункт, только если прошли его на тестовом сайте и, где сказано, в APK. Ширина телефона — около 375px.

## Вход

- [ ] Сайт `https://mfk096.github.io/-/` открывается и показывает вход, а не ошибку браузера.
- [ ] Неверный пароль — русское сообщение, без регистрации на экране.
- [ ] Верный вход попадает на главную. Обновление страницы не выбрасывает на чужой адрес.
- [ ] Прямая ссылка на единицу без сессии ведёт на вход и после входа открывает эту единицу.
- [ ] «Забыли пароль?» не падает. Смена своего пароля из меню сохраняется, старый пароль больше не входит.

## Пользователи (под администратором)

- [ ] Редактор и просмотр раздел «Пользователи» не ведут: видна фраза, что это только для администратора.
- [ ] Приглашение по email создаёт человека. Если письма нет, на экране есть временный пароль, им можно войти.
- [ ] Роль меняется. Свою роль сменить нельзя. Себя отключить нельзя.
- [ ] Отключённый входит и видит «Учётная запись отключена», списки ему недоступны.
- [ ] Одиннадцатый активный не создаётся. Сообщение по-русски.

## Учёт

- [ ] Номенклатура, место, единица, перемещение, смена статуса, поверка, журнал.
- [ ] Единицу нельзя сохранить без места и без статуса.
- [ ] В дереве мест нет поля «тип». Можно перенести узел к другому родителю и вставить уровень выше. Попытка зациклить дерево не проходит.
- [ ] Смена префикса при уже выданных кодах спрашивает подтверждение и пишет, сколько единиц затронет. После смены `KYOC-001` стал новым префиксом с тем же номером, списанная тоже. Журнал показывает новый код.
- [ ] Скан или поиск старого кода открывает единицу и жёлтое предупреждение «Этикетка устарела» с кнопкой печати новой этикетки.
- [ ] Старый код нельзя выдать другой единице.
- [ ] Этикетка печатается. QR с телефона открывает карточку на тестовом сайте (после входа).
- [ ] Склад: место в дереве плюс статус «Резерв». Отдельного статуса склада нет.
- [ ] Excel: выгрузка скачивается. Импорт единицы без места подсвечивает строку и не пишет файл. Импорт места без «вида» проходит.

## Телефон

- [ ] APK ставится по ссылке из README, без входа в Actions.
- [ ] Вход в те же данные, что на сайте.
- [ ] Нижнее меню не перекрывает кнопки. Длинные названия не вылезают за экран.
- [ ] Сканер читает новый QR и старый код после смены префикса.
- [ ] В настройках подключения адрес можно заменить и вернуть.

## Пустые и ошибки

- [ ] Пустой список говорит, что ничего нет, а не «в разработке».
- [ ] Обрыв сети или неверный адрес — русская фраза, приложение не закрывается.
