# Android-приложение

Оболочка Capacitor для телефона кладовщика. Имя на экране — «Инвентаризация», пакет `ru.factory.inventory`. Веб-сборка лежит внутри APK. Адрес Supabase в пакет не зашит навсегда: его вводят на телефоне.

## Скачать APK из GitHub Actions

1. Откройте репозиторий на GitHub → Actions → workflow **Android APK**.
2. Workflow запускается сам при push в `main` и вручную через **Run workflow**.
3. Дождитесь зелёного прогона. Внизу страницы блок **Artifacts**.
4. Скачайте `inventory-debug-apk`. Внутри `app-debug.apk`.
5. Если в секретах репозитория задан keystore, рядом появится `inventory-release-apk`. Без секретов release не собирается, debug при этом всё равно есть.

Секреты подписи, если release нужен:

| Секрет | Что это |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | Файл `.jks` или `.keystore`, закодированный в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | Пароль хранилища |
| `ANDROID_KEY_ALIAS` | Alias ключа |
| `ANDROID_KEY_PASSWORD` | Пароль ключа |

Keystore в git не кладётся.

## Поставить на телефон

1. Скопируйте `app-debug.apk` на телефон (кабель, почта, общая папка).
2. Откройте файл. Если система пишет, что установка из этого источника запрещена, разрешите её для того приложения, которым открыли файл (Файлы, Chrome и т.п.).
3. Подтвердите установку. Иконка — синий квадрат с меткой QR, подпись «Инвентаризация».
4. Debug-сборке не нужна подпись магазина. Для обновления ставьте следующий APK поверх: пакет тот же.

Камера используется нативным сканером и не требует HTTPS. Телефону нужны службы Google Play: ML Kit берёт распознавание оттуда. Если их нет, код с этикетки вводится вручную.

## Указать сервер

При первом запуске входа ещё нет.

1. На экране входа нажмите **Настройки подключения**.
2. Адрес — тот же, что `VITE_SUPABASE_URL`. Облако: `https://xxxx.supabase.co`. Сервер завода: `http://10.0.0.5:8000` (порт и хост ваши). Схема `http://` разрешена: в приложении включён cleartext.
3. Вставьте **anon key**. Ключ `service_role` приложение откажется сохранить.
4. **Проверить соединение** ходит в `/auth/v1/health`. Это необязательно: если телефон ещё не в сети завода, настройки можно сохранить и проверить позже.
5. **Сохранить на устройстве**. После этого экран входа принимает email и пароль этого сервера.
6. Когда завод переедет, откройте настройки снова (до входа или из меню администратора) и замените адрес. APK пересобирать не нужно. Сессия при смене сервера сбрасывается.

Значения `VITE_` из сборки — только запасной вариант, если на телефоне ещё ничего не сохраняли. В workflow сборки их нет, поэтому свежий APK ждёт адрес на экране настроек.

Кнопка «Назад» возвращает на предыдущий экран. На первом экране она закрывает приложение.

## Собрать debug APK у себя

Нужны Node.js 22, JDK 21 и Android SDK с платформой 36.

```bash
cd frontend
npm ci
npm run android:sync
```

`android:sync` собирает веб и копирует его в проект Android. Дальше:

```bash
cd android
./gradlew assembleDebug
```

Файл: `frontend/android/app/build/outputs/apk/debug/app-debug.apk`.

`local.properties` с путём к SDK создаёт Android Studio или его пишут вручную (`sdk.dir=...`). Этот файл в git не входит.
